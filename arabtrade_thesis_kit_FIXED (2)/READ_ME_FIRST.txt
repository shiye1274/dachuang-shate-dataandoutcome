你之前把 DeepSeek API Key 发到聊天里了，请去 DeepSeek 后台

【怎么跑】（文件名已改成英文，不会再乱码）
-----------------------------------------------------------
方法：直接双击下面的 .bat 文件即可。

  RUN_full_833.bat     ← 【主力】跑全部 833 题，出正式结果
  quick_test_30.bat    ← 先小测（每场景 30 题），确认 API 能通
  self_check.bat       ← 不花钱的自检，检查环境/数据/统计是否正常
  make_figure.bat      ← 生成一张四段式输出样例图

步骤：
1) 双击 RUN_full_833.bat
2) 粘贴你的（新的）DeepSeek API Key，回车
3) 等它跑。现在会【每完成一题就实时打印一行】，比如：
     [12/833] 正在处理 QA-0012（compliance）...
     [12/833] 完成 ✓
   只要数字在涨，就是在正常跑，不用担心。
4) 跑完后新结果在 results 文件夹里。

提示：全量 833 题会调很多次 API，可能要一两个小时；
     中途关窗了也不怕，下次双击会从断点继续（不会重复花钱）。
想省钱：在 RUN_full_833.bat 里的命令后面加 --no-judge，会改用
     免费的关键点覆盖率打分（不调用 LLM 评委，便宜很多）。

-----------------------------------------------------------
【我修好了什么】（大白话）
-----------------------------------------------------------
1. 检索几乎“瞎了”——已修复（影响最大）
   旧程序按“空格”切词去找知识库，但中文句子没空格，于是整句话
   被当成一个词去硬碰，几乎找不到资料（约 1/4 题目零检索）。
   修好后：零检索率 24.5% → 0%，每题都能找到资料。
2. “可解释性”得分是假满分——已修复
   旧评分只看有没有出现“合规/建议/风险/来源”标题词，而规则增强RAG
   本就被要求带这几个标题，所以永远 1.00（标准差 0）。现在改成看每段
   “是否真写了实质内容”，分数会真实波动。
3. 评测集混进了脚注编号和模板碎句——已清理
   清掉“ 1, 2”“问题,如何解决的?”等 1600 多处杂字，真实数字（150%、2025年）
   原样保留；题目总数仍 833，题型/场景分布一字未变。
4. 顺手修了显示小bug：负增益原来显示成“+-7.5%”，现在正确显示“-7.5%”。
5. （本版新增）屏幕会实时显示每一题的进度，不会再“没动静”。
